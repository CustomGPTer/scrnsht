# ScrnSht

ScrnSht is a free Android app that floats a see-through button over every app. One tap takes a screenshot with the status and navigation bars cropped off and saves it straight to your gallery. No adverts, no account.

Website: https://customgpter.github.io/scrnsht/

Download: https://github.com/CustomGPTer/scrnsht/releases/latest/download/ScrnSht.apk
